# Лидар на Orange Pi Zero 3 (YDLIDAR X3 Pro и SLAMTEC RPLIDAR C1)

Удешевлённый вариант к [Orange Pi 5B](../opi5b): плата без рабочего стола, карта помещения смотрится в браузере на компьютере (МОС ОС или Windows). Поддерживаются два лидара — YDLIDAR X3 Pro и SLAMTEC RPLIDAR C1, модель определяется автоматически.

- **Пошаговая инструкция со скриншотами (37 страниц):** [docs/OPiZero3_Lidar_Инструкция.pdf](docs/OPiZero3_Lidar_Инструкция.pdf)
- **Краткая инструкция для урока (4 страницы):** [docs/OPiZero3_Lidar_Демонстрация.pdf](docs/OPiZero3_Lidar_Демонстрация.pdf) — включить, подключиться к Wi-Fi платы, открыть карту в браузере.

## Структура папки

```
opi_zero3/
├── docs/     инструкции (PDF)
├── python/   чтение лидара без ROS
├── ros2/     запуск SLAM, расстояния, веб-страница, настройки
├── setup/    скрипты установки на плате
└── image/    снятие и тиражирование образа карты
```

## Система и подключение

- Карта microSD от 16 ГБ (eMMC у Zero 3 нет). Официальный образ **Orangepizero3_1.0.4_ubuntu_jammy_server_linux6.1.31** (Ubuntu 22.04 без рабочего стола), ROS 2 **Humble**.
- Питание платы — USB-C выход XS2 контроллера «Кибернетический» (5 В до 3 А). XS2 работает только при внешнем питании контроллера.
- Лидар через плату-адаптер: кабель данных — в USB-A платы (`/dev/ttyUSB0`), кабель питания — в USB-A аккумуляторного модуля 12V_3A_PowerBank.
- Перед выключением контроллера: `sudo poweroff` на плате и дождаться, пока погаснет зелёный светодиод.

| | YDLIDAR X3 Pro | RPLIDAR C1 |
|---|---|---|
| Драйвер, скорость порта | ydlidar_ros2_driver, 115 200 | sllidar_ros2, 460 800 |
| Частота `/scan` | 5,45 Гц | 10 Гц |
| Дальность карты | 8 м | 12 м |

## Показ карты

| Что | Адрес | Логин / пароль |
|---|---|---|
| Wi-Fi точка доступа платы | сеть `OrangePiZero3` (на копиях `OrangePiZero3-N`) | пароль `orangepizero3` |
| SSH | `10.42.0.1` | `orangepi` / `orangepi` |
| Lichtblick (основной способ) | `http://10.42.0.1:8081`, подключение `ws://10.42.0.1:8765` | — |
| Простая страница `lidar_web` | `http://10.42.0.1:8080` | — |

> ⚠ Это пароли по умолчанию, они подходят только для учебной локальной сети. Если плата подключается к другим сетям, смените их: `passwd` для пользователя, пароль точки доступа — вторым параметром `rename_board.sh`.

Lichtblick работает в Docker на самой плате: на компьютер ничего ставить не нужно, интернет и учётная запись не нужны. В панели 3D: Display frame `map` или `base_link`, топики `/map`, `/scan`, `/lidar_info`. Если в МОС ОС в VirtualBox появляется «Error creating WebGL context» — в Яндекс Браузере `browser://flags` → *Override software rendering list*.

Команды автозапуска: `slam_status`, `slam_log`, `slam_restart`, `slam_stop` (перед ручным `lidar_slam` — обязательно `slam_stop`).

## Готовый образ системы

Настроенную карту можно записать на другие платы из готового образа `opi_zero3_lidar_20261116.img.gz` (1,3 ГБ — в репозиторий не помещается; подходит для карт от 16 ГБ). Запись — balenaEtcher прямо из `.img.gz`, затем на каждой копии `sudo bash rename_board.sh N`. Порядок снятия и тиражирования образа — в инструкции.
