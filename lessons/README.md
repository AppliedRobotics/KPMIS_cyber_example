# Примеры к урокам — робототехнический контроллер «Кибернетический»

Примеры к учебным программам на 34 и 68 часов. Номер примера `NN` общий для обеих программ: в столбцах «Уроки 34 ч» и «Уроки 68 ч» указано, к каким урокам он относится. Программа на 34 часа использует 37 примеров, на 68 часов — все 51.

- `arduino_ide/Ardu8_NN_Название/` — скетч для Arduino IDE. Открывать файл `.ino`; папка и файл должны называться одинаково.
- `ar_bbl/Ardu8_NN_Название.xmlar` — тот же пример в AR BBL (открыть через «Открыть проект»). Есть не для всех: в AR BBL нет блоков для IMU, сервоприводов Feetech, шины DXL на ESP32 и приёма UART на ESP32.
- `Примеры_по_урокам.xlsx` — таблица: что делает каждый пример, к каким урокам относится, как подключить.

В начале каждого примера указаны плата, разъём USB-C и положение DIP-переключателя. Примеры намеренно простые, с подробными комментариями.

## Что нужно установить

- Arduino IDE с пакетом плат **esp32** (Espressif). Плата для Arduino-части — *Arduino Uno*, для ESP32 — *ESP32 Wrover Module*.
- Библиотека **DxlMaster2** (`../libraries/dxlmaster2-main.zip`) — для примеров с моторами на Arduino-части (38–44).
- Библиотека **FeetechSTS** (`../libraries/FeetechSTS.zip`) — для примеров с сервоприводами (46–51).
- Примеры ESP32 с моторами (33–37, 45) используют вкладку `dxl.h` в папке примера — ничего ставить не нужно.

## Проверка

- Все 51 пример Arduino IDE собраны компилятором (Arduino Uno; ESP32 Wrover Module, ядро esp32 3.3.3).
- 24 проекта AR BBL загружены в движок AR BBL без ошибок, их C++-код компилируется.
- На контроллере проверены проекты AR BBL, совпадающие с набором [`ar_bbl_examples`](../ar_bbl_examples) (07, 19, 20, 24, 26, 27, 29; 38 — по светодиодам драйверов). Остальное нужно прогнать на железе до урока.
- Примеры с IMU, поворотами робота, ездой по линии, сервоприводами и управлением с телефона — черновики для проверки: числовые параметры (размеры робота, коэффициенты, знаки моторов) подбираются на месте.
