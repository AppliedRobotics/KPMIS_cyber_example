# Обновление прошивки аккумуляторного модуля 12V_3A_PowerBank

Программы обновляют прошивку модуля до **версии 2** по шине DXL через USB-адаптер [USB-DXL-AR](../../docs/hardware/usb_dxl_ar.md). Прошивка встроена в программу, отдельных файлов не нужно. В версии 2 модуль без нагрузки выключается через 45 минут, а не через 5.

| Файл | Система | Статус |
|---|---|---|
| `powerbank_3S_update_to_2.exe` | Windows | ✅ проверен (Windows 11) |
| `powerbank_3S_update_to_2.mos` | МОС Desktop 12 | ✅ проверен (в VirtualBox) |
| `powerbank_3S_update_to_2` | Linux (нужна свежая glibc) | не проверен |

Пошаговая инструкция со скриншотами: [docs/update_powerbank_firmware.md](../../docs/update_powerbank_firmware.md).

Кратко:
1. Соединить разъём X2 адаптера с любым из разъёмов X3/X4/X5 модуля. Модуль работает от своих аккумуляторов.
2. Запустить программу (в МОС и Linux сначала `chmod +x`), ввести порт: `COMx` в Windows, `/dev/ttyUSB0` в МОС и Linux.
3. Включить модуль кнопкой и нажать Enter (ID 66 по умолчанию).
4. На «Нажмите и удерживайте несколько секунд» зажать кнопку питания модуля, пока не побегут точки.
5. Дождаться «Обновление успешно завершено».

Если модуль уже обновлён, программа сообщит, что версия 2, и ничего не изменит.
