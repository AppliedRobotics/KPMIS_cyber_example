# Библиотеки

Установка в Arduino IDE: **Скетч → Подключить библиотеку → Добавить .ZIP библиотеку** и выбрать архив.

| Архив | Для чего |
|---|---|
| `dxlmaster2-main.zip` | DxlMaster2 (Applied Robotics) — моторы по шине DXL с Arduino-части (уроки 38–44, `mecanum_4wd`, `board_tests/Ardu8_dxlmaster_test`). Занимает D2 как пин направления. |
| `FeetechSTS.zip` | FeetechSTS — сервоприводы Feetech ST3215 с ESP32 (уроки 46–51). Внутри примеры `Ardu8_ST3215_*`. |

Папка `FeetechSTS/` — исходники той же библиотеки, распакованные для просмотра на GitHub.
