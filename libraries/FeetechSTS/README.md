# FeetechSTS — сервоприводы Feetech ST3215 для Arduino IDE

Библиотека для сервоприводов Feetech серии **STS / ST** (ST3215, STS3215, STS3032 и др.) с последовательной шиной TTL. Основная платформа — **ESP32** (в том числе плата **Ardu8**), работает и с другими платами с аппаратным `HardwareSerial`.

## Установка

Arduino IDE → **Скетч → Подключить библиотеку → Добавить .ZIP библиотеку…** → выбрать `FeetechSTS.zip`.
Примеры появятся в **Файл → Примеры → FeetechSTS**.

## Подключение к Ardu8

| Что | Как |
|---|---|
| Разъём | 3-пиновые XP2 / XP3 (GND, VCC, DXL) — та же шина, что у модулей моторов |
| DIP-переключатель | **DIP3 = ON** (ESP32 на шине DXL), **DIP4 = OFF** |
| Пины ESP32 | RX = IO33, TX = IO32 → `bus.begin(Serial2, 1000000, 33, 32);` |
| Плата в IDE | ESP32 Dev Module (модуль ESP32-WROVER) |

Перед первым включением:

- **Питание.** На VCC шины идёт напряжение с XT60 / DC-входа без стабилизации. ST3215 бывают на 7,4 В и на 12 В — проверьте маркировку привода и что напряжение аккумулятора/БП в его пределах.
- **Распиновка разъёма.** Порядок GND / VCC / сигнал у Feetech совпадает с Dynamixel, но проверьте мультиметром, прежде чем вставлять — перепутанное питание сожжёт привод.
- **ID.** Заводской ID привода — 1. Модули моторов Ardu8 занимают ID **71 и 72**, их не используйте.
- **Скорость.** Заводская скорость ST3215 — 1 Мбит/с, модули моторов STM8 — 57600. На одной шине они не мешают друг другу (каждый отвечает только на свои пакеты).

### Если привод не находится на 1 Мбит/с

Схема автопереключения направления на Ardu8 проверена только на 57600 (модули моторов). Если пример **Scan** не видит привод, возможно, фронты сигнала на 1 Мбит/с слишком медленные. Тогда один раз переведите привод на 115200 или 57600 через другой адаптер (например, Feetech URT-1 / FE-URT и программа FD) или через `changeBaud()` на плате, где 1 Мбит/с работает. На 57600 приводы и моторы можно обслуживать одним `Serial2`.

## Быстрый старт

```cpp
#include <FeetechSTS.h>

FeetechBus bus;
FeetechServo servo(bus, 1);          // привод с ID 1

void setup() {
  Serial.begin(115200);
  bus.begin(Serial2, 1000000, 33, 32);
  servo.setMode(STS_MODE_POSITION);
  servo.hold();                      // удержание без рывка при старте
}

void loop() {
  servo.moveTo(1024, 2000, 50);      // позиция, скорость (шагов/с), ускорение
  delay(1500);
  servo.moveToDeg(270, 2000, 50);
  delay(1500);
  Serial.println(servo.readPosition());
}
```

## Примеры

| Пример | Что делает |
|---|---|
| `Ardu8_ST3215_Scan` | Ищет приводы на всех скоростях и ID, печатает модель, угол, напряжение, температуру |
| `Ardu8_ST3215_Position` | Режим позиции: кнопки ESP32 ставят 90° / 180° / 270° или отпускают вал; RGB показывает движение |
| `Ardu8_ST3215_Wheel` | Режим колеса: кнопки меняют скорость вращения |
| `Ardu8_ST3215_SetID` | Смена ID через монитор порта (на шине — один привод) |
| `Ardu8_ST3215_Sync` | Несколько приводов: синхронное движение (SYNC WRITE) и чтение (SYNC READ) |

Кнопки ESP32 на Ardu8 расположены слева направо в обратном порядке: BUT4 (IO26), BUT3 (IO25), BUT2 (IO35), BUT1 (IO34).

## Единицы

- Позиция: 0…4095 шагов на оборот, 2048 — середина. `degToPos()` / `posToDeg()` переводят в градусы.
- Скорость: шагов/с (4096 = 1 об/с). В `moveTo()` скорость 0 = максимальная.
- Ускорение: 0…254, 0 = без плавного разгона.
- Нагрузка: 0…1000 (0,1 %), знак — направление. Ток: единицы датчика (≈6,5 мА у ST3215).

## API

### FeetechBus — шина

| Функция | Описание |
|---|---|
| `begin(Serial2, baud, rx, tx[, dirPin])` | Запуск на ESP32 с выбранными пинами. `dirPin` — для внешнего драйвера с пином направления, на Ardu8 не нужен |
| `setBaudRate(baud)` | Сменить скорость шины на лету |
| `setTimeout(ms)` | Тайм-аут ответа (по умолчанию 10 мс) |
| `ping(id)` | Есть ли привод с таким ID |
| `read / write(id, addr, data, len)` | Чтение / запись произвольных регистров |
| `readByte / readWord / writeByte / writeWord` | То же для 1 и 2 байт |
| `regWrite(...)` + `action()` | Отложенная запись и одновременный запуск |
| `syncWrite(addr, len, ids, data, n)` | Запись многим приводам одним пакетом |
| `syncRead(addr, len, ids, n, out[, ok])` | Чтение у многих приводов одним запросом |
| `syncMoveTo(ids, pos, n, speed, acc)` | Одновременное движение до 35 приводов |
| `syncReadPositions(ids, n, pos)` | Положения до 124 приводов |
| `lastError()` | `STS_OK`, `STS_ERR_TIMEOUT`, `STS_ERR_CHECKSUM`, `STS_ERR_PARAM` |
| `lastServoStatus()` | Байт ошибок из ответа привода (перегрев, напряжение, перегрузка…) |
| `echo()` / `setEcho()` | Слышит ли приёмник собственную передачу. Определяется автоматически в `begin()` |

### FeetechServo — привод

| Функция | Описание |
|---|---|
| `ping()`, `torque(on)`, `setMode(mode)` | Связь, удержание вала, режим (`STS_MODE_POSITION`, `_WHEEL`, `_PWM`, `_STEP`) |
| `hold()` | Включить удержание в текущем положении (цель = текущий угол), чтобы вал не дёрнулся к старой цели |
| `moveTo(pos, speed, acc)`, `moveToDeg(deg, speed, acc)` | Режим позиции |
| `regMoveTo(...)` | Отложенное движение до `bus.action()` |
| `setSpeed(speed, acc)` | Режим колеса |
| `setPWM(-1000..1000)` | Режим ШИМ (открытый контур) |
| `setTorqueLimit(0..1000)` | Ограничение момента |
| `readPosition()`, `readDeg()`, `readSpeed()`, `readLoad()`, `readCurrent()`, `readTemperature()`, `readVoltage()`, `isMoving()` | Обратная связь. При ошибке — `STS_READ_ERROR` (напряжение — `NAN`) |
| `readState(st)` | Всё сразу одним запросом (структура `STSState`) |
| `readModel(model)` | Номер модели |
| `changeId(newId)` | Новый ID с сохранением в EEPROM |
| `changeBaud(STS_BAUD_...)` | Новая скорость привода (и шины) |
| `setAngleLimits(min, max)` | Пределы угла в режиме позиции |
| `calibrateMiddle()` | Текущее положение вала станет серединой (2048) |

## Что требует проверки на железе

- Работа автонаправления Ardu8 на 1 Мбит/с (см. выше).
- Режим ШИМ (`setPWM`): по документации Feetech скважность пишется в регистр 44 со знаком в 10-м бите.
- `SYNC READ` есть не во всех старых прошивках приводов — пример `Sync` при неудаче читает приводы по одному.
