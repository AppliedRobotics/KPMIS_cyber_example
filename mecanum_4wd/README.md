# Мобильная платформа 4WD с меканум-колёсами

Скетчи для платформы на контроллере «Кибернетический» (Ardu8).

| Скетч | Плата | Что делает | Статус |
|---|---|---|---|
| `Ardu8_Mecanum_Test` | Uno | Тест датчиков, колёс, энкодеров и движений | ✅ проверен 03.11.2026 |
| `Ardu8_Mecanum_Sensors` | Uno | Arduino-часть пульта: датчики и IMU → ESP32 по UART | ✅ проверен |
| `Ardu8_esp_Mecanum_Web` | ESP32 | Пульт по Wi-Fi, страница в `page.h` | ✅ проверен |

## Подключение платформы

- Моторы (порты на правом краю, сверху вниз): FL — порт 3, FR — порт 2, RL — порт 4, RR — порт 1.
- Датчики линии слева направо: D3 (левый внешний), D6 (левый внутренний), D4 (правый внутренний), D7 (правый внешний).
- Ультразвуковой дальномер: TRIG — A0, ECHO — A1.
- Концевые выключатели: левый — D5, правый — A2.
- IMU ICM-20948 — на плате контроллера (I2C, A4/A5).
- Питание моторов — от XT60 или DC, выключатель питания в ON.

## Тест (`Ardu8_Mecanum_Test`)

DIP: 1 — OFF, 2 — OFF, 3 — OFF, 4 — ON, 5 — ON. Прошивать при DIP4 = OFF, затем включить DIP4.
Нужна библиотека DxlMaster2 (`../libraries/dxlmaster2-main.zip`).

## Пульт по Wi-Fi (`Ardu8_Mecanum_Sensors` + `Ardu8_esp_Mecanum_Web`)

DIP: 1 — OFF, 2 — ON, 3 — ON, 4 — OFF, 5 — ON. Прошивать оба контроллера можно, не меняя переключателей.

1. Подключиться к сети Wi-Fi «Kibernetichesky-4WD», пароль `12345678`.
2. Открыть в браузере http://192.168.4.1.

На странице: управление движением, показания датчиков, значения IMU по осям X/Y/Z, крен и тангаж (по акселерометру), курс (по магнитометру, без калибровки).

Безопасность:
- без связи со страницей больше 0,4 с платформа останавливается;
- вперёд не едет, если препятствие ближе 15 см (можно отключить на странице);
- кнопка 3 Arduino — аварийный стоп.

Индикация ESP32: RGB синий — ждёт подключения, зелёный — пульт подключён, красный — нет данных от Arduino или не отвечает модуль моторов.
