# Инструкции

| Инструкция | Что внутри |
|---|---|
| [Установка Arduino IDE в МОС Desktop 12](install_arduino_ide_mos.md) | Установка из репозитория МОС, доступ к USB-портам, проверка сборки и загрузки скетча |
