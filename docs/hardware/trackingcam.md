# Модуль технического зрения TrackingCam v3

Инфографика: [A4, 3 страницы](infographics/TrackingCam3_A4.pdf) · Инструкция по интерфейсу настройки: [PDF, 121 страница](../pdf/TrackingCam3_Интерфейс_настройки_технического_зрения.pdf)

Камера со своим Linux-компьютером (плата v3.1). Модуль сам распознаёт объекты и передаёт результаты контроллеру «Кибернетический» по шине Dynamixel.

## Характеристики

| Параметр | Значение |
|---|---|
| Процессор | Allwinner H3, 4 ядра Cortex-A7, 1,2 ГГц |
| Память | 512 МБ DDR3, eMMC 8 ГБ, слот microSD |
| Камера | OV5640, 5 Мп, объектив M12 (резкость — вращением объектива) |
| Операционная система | Linux, можно устанавливать своё ПО |
| Беспроводная связь | Wi-Fi 802.11 b/g/n, Bluetooth 4.0 (модуль AP6212, разъём U.FL для внешней антенны) |
| Связь с контроллером | Dynamixel TTL (протокол 1.0 / 2.0) или UART |
| Интерфейсы | UART ×2 и отладочный, SPI, I2C, I2S, USB host ×2, Ethernet |
| Питание | 5,2–16 В по шине DXL или 5 В от mini-USB |
| Габариты | 56 × 41 × 33 мм |

## Разъёмы

| Разъём | Назначение |
|---|---|
| DXL ×2 | Шина Dynamixel, Molex SPOX: 1 GND · 2 VCC · 3 DATA. Второй разъём — для цепочки устройств |
| mini-USB | Настройка, видео и данные; в компьютере определяется как сетевая карта (RNDIS). Питание 5 В |
| Верхняя колодка 2 × 12 | I2S, SPDIF, ИК-приёмник, 2 × USB host, отладочный UART, линейный выход и микрофон, Ethernet |
| Нижняя колодка 2 × 12 | Питание, I2C, UART1 и UART2, SPI, GPIO — как первые 24 вывода Raspberry Pi |
| microSD | Накопитель; с карты 8–16 ГБ восстанавливается образ ОС |
| Кнопка SW1 | Подключена к выводу процессора |

Все выводы колодок подписаны на радиаторе-накладке. GPIO нижней колодки (G11, TX2, RX2, PA2, PA3, PA6, PG8, PG9) работают только с уровнем 3,3 В — подавать на них 5 В нельзя.

## Подключение к контроллеру «Кибернетический»

Кабель DXL от любого разъёма камеры — к разъёму шины DXL контроллера. На той же шине могут быть аккумуляторный модуль и сервоприводы.

- По умолчанию у камеры **ID 1** и скорость **1 Мбит/с**. ID на шине должен быть уникальным, скорость — общей для всех устройств.
- Контроллер читает результаты командой READ из регистров камеры. Раскладка регистров выбирается в Camera Manager.
- Питание по шине — 5,2–16 В, аккумуляторный модуль 12 В подходит. Если по USB не хватает питания, подайте 12 В по DXL.
- Если вместо видео белый экран — модуль перегрелся: отключите питание на несколько минут.

## Первое включение

1. Подключите mini-USB к компьютеру или подайте 12 В по шине DXL.
2. Дождитесь, пока красный светодиод загорится, а зелёный начнёт мигать.
3. Откройте в браузере `http://trackingcam3.local` или `192.168.42.1`.
4. Включите нужный детектор, настройте его и нажмите «Сохранить».
5. В Camera Manager (`http://trackingcam3.local:9999/dynamixelslave`) выберите раскладку регистров детектора, задайте ID, версию протокола и скорость — такие же, как в программе контроллера.

| Что | Адрес / параметры |
|---|---|
| Веб-интерфейс настройки | `http://trackingcam3.local` |
| Администрирование (службы, сеть, обновление) | порт `9999`, `root` / `12345` |
| Camera Manager — раскладка регистров DXL | `:9999/dynamixelslave` |
| Wi-Fi точка доступа | `trackingcam3-xxxxxx`, пароль `12345678` |
| Режим порта | «Настройки» → «Вкл. UART» (выключено — шина DXL) |

> ⚠ Это пароли по умолчанию, они подходят только для учебной локальной сети. Для работы в других сетях смените их в разделе администрирования.

## Функции встроенного ПО

Каждый детектор настраивается в браузере, результат контроллер читает по шине DXL.

| Детектор | Что передаёт контроллеру | Раздел инструкции |
|---|---|---|
| Цветные объекты (до 10 шаблонов цвета, YCbCr) | Центр, площадь, рамка | 2 |
| Маркеры ArUco | Номер и координаты маркера | 3 |
| Положение (поза камеры по опорным маркерам) | Поворот и перенос | 4–5 |
| Прямые линии | Отрезки и точка пересечения | 6 |
| Кривые | Рамка, длина, кривизна | 7 |
| Окружности заданного радиуса | Центр и радиус | 8 |
| Цветные фигуры HSV (треугольники, квадраты, круги) | Параметры фигур | 9 |
| Объекты на поле 6 × 6 | Код цвета клеток | 10 |
| Поле по ArUco 10 × 10 | Номера маркеров в клетках | 11 |
| Нейросеть (YOLO) | Класс, рамка, уверенность | 12 |
| Обучение нейросети на камере | Своя модель, хранится в модуле | 13 |
| Настройки камеры | Экспозиция, баланс белого, режим порта | 14 |

## Программирование

- **Arduino:** библиотеки TrackingCamDxl и TrackingCamDxlUart.
- **ROS:** пакет tc3-ros-package — топики блобов, маркеров, линий, окружностей и изображения.
- **Своё ПО** — средствами Linux модуля: доступ к видео, памяти и интерфейсам.
