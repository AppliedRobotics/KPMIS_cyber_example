# Модули датчиков Kirus

Инфографика (A4): [«Концевой выключатель»](infographics/Kirus_uSW_A4.pdf) · [«Датчик линии»](infographics/Kirus_Line_A4.pdf) · [«Ультразвуковой дальномер»](infographics/Kirus_Ultrasonic_A4.pdf)

Производитель модулей — ООО «ЭДУТЕХНИКС» (EDU Technics).

| Обозначение | Наименование |
|---|---|
| Kirus-uSW V1.0 | Модуль «Концевой выключатель» |
| Kirus-Line V2.0 | Модуль «Датчик линии» |
| Kirus-Ultrasonic V1.0 | Модуль «Ультразвуковой дальномер» |

## Общие разъёмы

- **X2, X4** — 3-пиновые JST EH: сигнал · 5V · GND. Такие же, как 3-пиновые разъёмы контроллера «Кибернетический» — модуль подключается прямым кабелем.
- **X1** — RJ12, **X3** — гребёнка 1×6 рядом с ним (одинаковая разводка): 1, 2 — не подключены · 3 — 5V · 4 — сигнал 1 · 5 — сигнал 2 · 6 — GND.
- На каждом модуле есть светодиод питания «PWR».

Модули подключаются к Arduino-части контроллера: у ESP32 нет разъёмов для датчиков, а сигналы модулей 5-вольтовые.

## Модуль «Концевой выключатель» (Kirus-uSW)

- Микропереключатель с рычагом, подтяжка к 5 В.
- **Не нажат = HIGH, нажат = LOW.**
- Светодиоды: «PWR» (красный) и «SIG» (зелёный, горит при нажатии).
- Оба 3-пиновых разъёма одинаковые (SIG). В RJ12 сигнал на контакте 5.

## Модуль «Датчик линии» (Kirus-Line)

- Два оптрона TCRT5000 снизу и компаратор. Выходы только цифровые.
- **Белое = LOW** (зелёный светодиод канала горит), **чёрное = HIGH**.
- Общий порог чувствительности — подстроечный резистор R7 сверху.
- Каналы: S1 — оптрон IR1, разъём «S1 5V GND» (слева); S2 — оптрон IR2, разъём «S2 5V GND» (справа). Каждый разъём со стороны своего оптрона.
- Светодиоды: «PWR», «LED1» (канал S1), «LED2» (канал S2).

**Настройка порога:** поставить модуль на белое — светодиоды LED1/LED2 горят; подвести к чёрной линии — гаснут. Если нет, подкрутить R7.

## Модуль «Ультразвуковой дальномер» (Kirus-Ultrasonic)

- Внутри — HC-SR04. Разъёмы «TRIG 5V GND» и «ECHO 5V GND».
- Расстояние, см ≈ длительность импульса ECHO, мкс / 58.
- Уровень ECHO — 5 В: к ESP32 напрямую подключать нельзя.
- Светодиоды горят при **низком** уровне на своей линии: **LED1** — ECHO (в покое горит, во время измерений мигает), **LED2** — TRIG (горит, когда скетч держит TRIG в LOW).

## Подключение к контроллеру

Проверенная раскладка, все три модуля одновременно:

| Модуль | Разъём модуля | Пин контроллера |
|---|---|---|
| Датчик линии | S1 5V GND | D3 |
| Датчик линии | S2 5V GND | D4 |
| Ультразвуковой дальномер | TRIG 5V GND | D5 |
| Ультразвуковой дальномер | ECHO 5V GND | D6 |
| Концевой выключатель | SIG 5V GND (любой) | D7 |

D2 остаётся свободным для библиотеки DxlMaster2.

Через RJ12 одним кабелем модуль подключается только в разъём **I2C** контроллера: сигнал 1 → A4, сигнал 2 → A5. В разъём CAN не подключать — там контакты 4/5 заняты линиями CAN.
