# USB-адаптер USB-DXL-AR

Инфографика: [A4, 2 страницы](infographics/USB-DXL-AR_A4.pdf)

Производитель — ООО «Прикладная робототехника ПРО» (Applied Robotics PRO), версия V2.1.

## Назначение

Связь компьютера с устройствами на шине Dynamixel TTL: настройка, диагностика, обновление прошивки. Например, обновление [аккумуляторного модуля](powerbank.md) или настройка сервоприводов Feetech в [веб-настройщике](../../manipulator) (режим «USB-адаптер»).

## Характеристики

| Параметр | Значение |
|---|---|
| Подключение к ПК | mini-USB, питание адаптера 5 В от USB |
| Преобразователь | CH340G (Windows — «USB-SERIAL CH340 (COMx)», Linux и МОС ОС — `/dev/ttyUSB0`) |
| Шина | Dynamixel TTL, полудуплекс, 1 линия данных |
| Разъём шины | Molex 22035035, 3 контакта |
| Направление передачи | Автоматически, по сигналу TXD |
| Проверенные скорости | 57 600 бод и 1 Мбит/с |
| Системы | Windows, МОС ОС, Linux |

## Разъёмы и индикация

| Обозначение | Назначение |
|---|---|
| X1 | mini-USB — к компьютеру |
| X2 | Шина TTL: 1 DATA · 2 VDD · 3 GND (как у Dynamixel и разъёмов аккумуляторного модуля) |
| X3 | Место под RS-485 — **не установлено** |
| VCC | Есть питание от USB |
| LINK | Порт открыт программой |
| RX, TX | Обмен данными |

## Подключение

Компьютер → USB → адаптер (разъём X2) → кабель 3-pin → устройство на шине.

- **Адаптер не питает шину:** контакт VDD с USB не связан. Устройства на шине должны питаться сами.
- В Linux и МОС ОС пользователь должен входить в группу `dialout`.
- В виртуальной машине VirtualBox адаптер передаётся в гостевую систему через «Устройства → USB → QinHeng Electronics USB Serial».
- Работает только шина TTL: микросхема RS-485 на плате не установлена.
- У сервоприводов Feetech обычно другой разъём — нужен переходник.
