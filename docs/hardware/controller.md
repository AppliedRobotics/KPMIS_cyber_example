# Робототехнический контроллер «Кибернетический»

Инфографика: [A4, 2 страницы](infographics/Kibernetichesky_A4.pdf)

Плата Arduino V8.3, производитель ООО «Прикладная робототехника ПРО» (Applied Robotics PRO). В именах скетчей и папок примеров используется рабочее название **Ardu8**.

## Состав

- **ATmega328P**, 16 МГц, 5 В — совместим с Arduino Uno (в Arduino IDE плата *Arduino Uno*). Свой USB-C + CH340G.
- **ESP32-WROVER**, 3,3 В — Wi-Fi и Bluetooth (в Arduino IDE плата *ESP32 Wrover Module*). Свой USB-C + CH340G, автозагрузка, кнопки BOOT и EN.
- **2 × STM8S003** — модули моторов, по 2 мотора с энкодерами на каждом (драйверы DRV8876). Управляются по шине **DXL** (протокол Dynamixel 1.0).
- **ICM-20948** — 9-осевой IMU (акселерометр, гироскоп, магнитометр) на I2C Arduino.
- **MCP2551** — CAN-трансивер, подключён к ESP32.
- У Arduino и у ESP32 свой набор: 4 кнопки, 4 зелёных светодиода, RGB-светодиод. У ESP32 ещё пищалка.
- **DIP-переключатель** на 5 позиций коммутирует связи между узлами.
- Кнопка **RESET** сбрасывает ATmega328P, светодиоды Arduino и оба модуля моторов.

## Внешний вид

- Слева вверху — разъём XT60, под ним выключатель питания. DC-разъём — справа по центру.
- USB-C на левом краю: **верхний — Arduino**, **нижний — ESP32**. USB-C сверху — выход питания с быстрой зарядкой.
- Сверху — 12 трёхпиновых разъёмов (A0–A2, D2–D10), в центре — гребёнки в формате Arduino Uno.
- Правый край — 4 разъёма моторов.
- Снизу — два RJ12 (I2C и CAN), два 3-пиновых разъёма шины DXL, разъёмы UART, I2C, SPI.
- В центре — DIP-переключатель, разъём ICSP и пищалка. **Верхняя группа** кнопок и светодиодов — Arduino, **нижняя** (у модуля ESP32) — ESP32.

## Питание

- Вход: XT60 или DC-разъём → выключатель → шина **VCC** (моторы, сервоприводы, разъёмы RJ12).
- VCC → понижающий преобразователь → **5 В** → стабилизатор → **3,3 В**.
- Каждый USB-C (Arduino и ESP32) тоже даёт 5 В — для отладки логики без внешнего питания. Моторы и сервоприводы при этом не работают.
- Верхний USB-C — **выход** питания с быстрой зарядкой для внешних устройств.

## Arduino (ATmega328P)

| Пин | Назначение |
|---|---|
| D0, D1 | `Serial`: USB **и** шина DXL (через DIP4) **и** связь с ESP32 (через DIP1/DIP2) |
| D2–D7 | Свободны, 3-пиновые разъёмы (сигнал · 5V · GND) и гребёнка |
| D8 | Защёлка 74HC595 (светодиоды) — **не использовать для другого** |
| D9 | Загрузка 74HC165 (кнопки) — **не использовать для другого** |
| D10 | Выход 74HC165 на MISO |
| D11, D12, D13 | SPI: MOSI, MISO, SCK (светодиоды, кнопки, разъём SPI) |
| A0, A1, A2 | Свободны, 3-пиновые разъёмы |
| A3 | Свободен, только на гребёнке |
| A4, A5 | I2C: IMU ICM-20948 (0x68, магнитометр 0x0C), разъём I2C, RJ12 |

### Светодиоды — через 74HC595

SPI + защёлка D8. **0 в бите — светодиод горит.** Светодиоды работают только при **DIP5 = ON**.

| Бит | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| Светодиод | LED1 | LED2 | LED3 | LED4 | RGB синий | RGB зелёный | RGB красный |

### Кнопки — через 74HC165

D10 → LOW, импульс на D9 (LOW → HIGH), `SPI.transfer(0)`, D10 → HIGH. Биты 0–3 — кнопки BUT1–BUT4 слева направо. Нажатие = **1**.

## ESP32

| GPIO | Назначение |
|---|---|
| IO1 / IO3 | `Serial` → USB |
| IO22 (RX), IO23 (TX) | UART-связь с Arduino (через DIP1/DIP2) |
| IO32 (TX), IO33 (RX) | Шина DXL (через DIP3) |
| IO5 (TX), IO4 (RX) | CAN → RJ12 |
| IO27, IO14, IO12, IO13 | LED1–LED4 |
| IO15, IO2, IO18 | RGB: красный, зелёный, синий |
| IO34, IO35, IO25, IO26 | Кнопки BUT1–BUT4 |
| IO19 | Пищалка (`tone(19, частота, мс)`) |

Светодиоды: **LOW — горит**. Кнопки: нажатие = **HIGH**. Кнопки ESP32 на плате расположены в обратном порядке: слева направо BUT4, BUT3, BUT2, BUT1.

## DIP-переключатель

| № | ON = соединяет |
|---|---|
| 1 | ESP32 TX (IO23) → Arduino RX (D0) |
| 2 | Arduino TX (D1) → ESP32 RX (IO22) |
| 3 | ESP32 ↔ шина DXL |
| 4 | Arduino ↔ шина DXL |
| 5 | Включает светодиоды Arduino |

- У Arduino один `Serial` на USB, шину DXL и ESP32. **Прошивать Arduino при DIP1 и DIP4 = OFF.**
- **DIP3 и DIP4 одновременно не включать** — шиной управляет один контроллер.

## Шина DXL и моторы

- Протокол Dynamixel 1.0, модули моторов на **57 600 бод**, **ID 71 и 72**.
- Разъёмы моторов (6 пин): 1 M+ · 2 5V · 3 EncA · 4 EncB · 5 GND · 6 M−.

| Разъём (сверху вниз) | ID | Канал | Мощность / энкодер / скорость |
|---|---|---|---|
| 1 | 71 | M1 | рег. 28 / 32 / 40 |
| 2 | 71 | M2 | рег. 30 / 36 / 42 |
| 3 | 72 | M1 | рег. 28 / 32 / 40 |
| 4 | 72 | M2 | рег. 30 / 36 / 42 |

Основные регистры модуля:

| Адрес | Регистр | Описание |
|---|---|---|
| 24 | MAX_POWER | 0..1023, ограничение мощности в режиме скорости |
| 27 | ENCODER_MODE | 0 выкл, 1 AB, 2 A (оба фронта), 3 A по фронту (по умолчанию) |
| 28 / 30 | M1 / M2_POWER | −1023..1023, запись включает режим ШИМ |
| 32 / 36 | M1 / M2_ENCODER | тики энкодера (только чтение) |
| 34 / 38 | M1 / M2_PRESENT_SPEED | тики за 100 мс |
| 40 / 42 | M1 / M2_GOAL_SPEED | тики за 100 мс, запись включает режим скорости (PID) |
| 45 | SPEED_PERIOD | период регулятора, мс (по умолчанию 50) |
| 47–49 | PID_P / I / D | по умолчанию 16 / 32 / 0 |

Длина пакета ограничена: за одну запись — не больше 7 байт данных.

**Подключение к шине:**
- **ESP32:** DIP3 = ON, DIP4 = OFF. `Serial2.begin(57600, SERIAL_8N1, 33, 32)`. Отладка — по USB через `Serial`.
- **Arduino:** DIP4 = ON, DIP3 = OFF, DIP1 = OFF. Библиотека **DxlMaster2** работает без изменений, но занимает **D2** как пин направления. Вывод `Serial.print` попадает на шину — для отладки удобнее светодиоды.

## Сервоприводы Feetech ST3215

- Подключаются в 3-пиновые разъёмы шины DXL. **DIP3 = ON, DIP4 = OFF.**
- Библиотека **FeetechSTS**: `bus.begin(Serial2, 1000000, 33, 32);` — заводская скорость приводов 1 Мбит/с работает.
- Заводской ID привода — 1. ID 71 и 72 заняты модулями моторов.
- Питание приводов идёт с VCC без стабилизации — напряжение должно подходить приводу (ST3215 бывают на 7,4 В и на 12 В).
