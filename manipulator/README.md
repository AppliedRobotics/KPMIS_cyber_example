# Конфигуратор манипулятора

Веб-приложение для настройки сервоприводов Feetech ST3215, подготовки их к сборке и управления манипулятором через робототехнический контроллер «Кибернетический» (Ardu8) или USB-адаптер [USB-DXL-AR](../docs/hardware/usb_dxl_ar.md).

Манипуляторов два — **металлический** (основной) и **пластиковый**. Обе модели — КТ.0002.04Г, 6 суставов + схват, но кинематика у них разная.

| Файл | Что это |
|---|---|
| `manipulator_tool.html` | Приложение «Конфигуратор манипулятора». Открывается двойным щелчком в Chrome, Edge или Яндекс Браузере (нужен Web Serial). Работает без интернета: three.js, 3D-модели обоих манипуляторов и запасные картинки встроены в файл |
| `Ardu8_Feetech_Bridge/` | Скетч-мост «USB ↔ шина DXL» для ESP32 контроллера. Без него приложение не видит сервоприводы через контроллер |
| [`Инструкция_Конфигуратор_манипулятора.pdf`](Инструкция_Конфигуратор_манипулятора.pdf) | Инструкция по работе с приложением (22 страницы) |

Детали пластикового манипулятора для 3D-печати — в папке [`3d_print`](../3d_print). Примеры работы с сервоприводами из скетчей — в библиотеке [`FeetechSTS`](../libraries) и в уроках 46–51 ([`lessons`](../lessons)).

## Подключение

**Через робототехнический контроллер «Кибернетический»:**
1. Прошить `Ardu8_Feetech_Bridge` в ESP32: нижний USB-C, плата *ESP32 Wrover Module*.
2. DIP3 = ON, DIP4 = OFF (шиной управляет ESP32).
3. Сервопривод — в 3-пиновый разъём XP2 или XP3. Питание — внешнее (XT60 или DC), напряжение должно подходить сервоприводам.
4. Закрыть монитор порта Arduino IDE.
5. В приложении выбрать «Кибернетический» и порт CH340 нижнего USB-C.

**Через USB-адаптер USB-DXL-AR:** выбрать «USB-адаптер», порт открывается на скорости шины. Адаптер шину не питает — сервоприводам нужно своё питание.

**«Демо»** — виртуальная шина: семь сервоприводов манипулятора (ID 1–7) и модули моторов контроллера (ID 71, 72). Можно познакомиться с приложением без оборудования.

## Разделы

### Один сервопривод
Поиск по ID и скоростям (модули моторов 71/72 помечаются как «не привод»), телеметрия 10 раз/с, круг положения с перетаскиванием цели, удержание и отпускание вала, режимы «позиция» и «колесо», калибровка середины, все параметры EEPROM, смена ID и скорости, таблица регистров 0–70, журнал пакетов.

### Подготовка сервоприводов к сборке
Вверху раздела выбирается манипулятор: металлический или пластиковый. Новые ST3215 приходят с ID 1, вал в случайном положении. Помощник проводит по очереди все 7 сервоприводов (подключать по одному):
1. Найти сервопривод.
2. Записать ID (по умолчанию 1–7 по суставам), скорость 1 Мбит/с, режим «позиция», пределы угла 0–4095.
3. Повернуть вал в середину (2048, 180°) и удерживать.
4. Надеть приводной фланец: 4 отверстия крестом «+» вдоль/поперёк длинной стороны корпуса, центральный винт М3, риска маркером на фланце и корпусе, подпись «ID N». После «Фланец надет» момент снимается.

3D-вид показывает фланец крупно и место сервопривода в манипуляторе. Прогресс подготовки не сохраняется: после перезагрузки страницы помощник начинает с первого сервопривода. Схват (ID 7): шестерни ставить при полностью раскрытых губках.

### Манипулятор (металл) и Манипулятор (пластик)

| Сустав | ID | Металлический | Пластиковый |
|---|---|---|---|
| 1 | 1 | Поворот основания | Поворот основания |
| 2 | 2 | Плечо | Плечо |
| 3 | 3 | Локоть | Локоть |
| 4 | 4 | Наклон кисти | Поворот предплечья |
| 5 | 5 | Поворот кисти | Наклон кисти |
| 6 | 6 | Наклон схвата | Поворот схвата |
| Схват | 7 | Схват (шестерни, параллелограмм) | Схват (тот же узел) |

- При каждом запуске выбран металлический манипулятор. Настройки суставов и позы хранятся отдельно для каждого типа.
- Поза модели (все суставы 0°): плечо вертикально, предплечье и кисть горизонтально вперёд, схват смотрит вниз и раскрыт (0° — раскрыт, 70° — сомкнут).
- Для каждого сустава задаются ID, ноль, инверсия и пределы. «Принять текущую позу за позу модели» записывает текущее положение в сервопривод как середину.
- Движение — SYNC WRITE: все суставы приходят в точку одновременно за заданное время. Реальное положение читается ~10 раз/с.
- Позы можно запоминать, проигрывать по порядку и по кругу. Настройки и позы сохраняются в браузере и в JSON-файл (отдельный файл для каждого типа).

#### Управление схватом в пространстве

Работает для обоих манипуляторов. Схват двигается по прямой, пока нажата кнопка: вперёд/назад, влево/вправо, вверх/вниз, наклон и поворот схвата, разомкнуть/сомкнуть. Углы суставов приложение считает само (обратная задача кинематики). Ориентацию схвата можно держать неизменной; скорость — медленно, средне, быстро.

- Клавиатура: стрелки — вперёд/назад/влево/вправо, PageUp/PageDown — вверх/вниз, R/F — наклон, Q/E — поворот схвата, O/C — разомкнуть/сомкнуть.
- Точку можно задать числами (X, Y, Z в мм, наклон и поворот схвата в градусах) и нажать «Перейти по прямой». «Подставить текущие» заполняет поля текущим положением, «Схват вертикально вниз» выставляет схват вниз.
- Столкновения звеньев между собой и со столом приложение не проверяет.

## Протокол моста

USB 1 000 000 бит/с. Кадр: `A5 5A CMD LEN DATA XOR`, где XOR = CMD ^ LEN ^ байты DATA.

| CMD | Назначение | Ответ |
|---|---|---|
| 1 | Версия | `FTBR1` |
| 2 | Скорость шины (4 байта LE) | Установленная скорость |
| 3 | Обмен: таймаут_мс + пакет Feetech | Байты с шины без эха |
| 4 | Поиск: ID_от, ID_до, таймаут_мс | Список ответивших ID |

Светодиоды ESP32: LED1 — мост работает, LED2 — обмен, RGB зелёный/красный — сервопривод ответил/нет ответа.

## Если не работает 3D

При ошибке WebGL приложение пробует упрощённые режимы, а если не получается — показывает встроенные картинки. Что проверить: аппаратное ускорение в настройках браузера, `chrome://gpu` (`browser://gpu` в Яндекс Браузере), `chrome://flags` → «Override software rendering list», драйвер видеокарты или 3D в виртуальной машине. Без 3D всё остальное работает.
