# Манипулятор на сервоприводах Feetech ST3215

Веб-настройщик сервоприводов Feetech и управление манипулятором КТ.0002.04В (6 осей + схват) с робототехнического контроллера «Кибернетический» (Ardu8).

| Файл | Что это |
|---|---|
| `feetech_tool.html` | Веб-страница «Настройщик Feetech». Открывается двойным щелчком в Chrome, Edge или Яндекс Браузере (нужен Web Serial). Работает без интернета: three.js, 3D-модель и запасные картинки встроены в файл |
| `Ardu8_Feetech_Bridge/` | Скетч-мост «USB ↔ шина DXL» для ESP32 контроллера. Без него страница не видит приводы |

Примеры работы с приводами из скетчей — в библиотеке [`FeetechSTS`](../libraries) и в уроках 46–51 ([`lessons`](../lessons)).

## Подключение

**Через контроллер «Кибернетический»:**
1. Прошить `Ardu8_Feetech_Bridge` в ESP32: нижний USB-C, плата *ESP32 Wrover Module*.
2. DIP3 = ON, DIP4 = OFF (шиной управляет ESP32).
3. Привод — в 3-пиновый разъём XP2 или XP3. Питание приводов — внешнее (XT60 или DC), напряжение должно подходить приводу.
4. Закрыть монитор порта Arduino IDE.
5. На странице выбрать режим «Ardu8» и порт CH340 нижнего USB-C.

**Через USB-адаптер Feetech** (URT-1, FE-URT): режим «USB-адаптер», порт открывается на скорости шины.

**«Демо»** — виртуальная шина (приводы ID 1–7, модули моторов 71/72) для знакомства с интерфейсом без железа.

## Разделы страницы

### Один привод
Поиск по ID и скоростям (модули моторов 71/72 на 57600 помечаются как «не привод»), телеметрия 10 раз/с, круг положения с перетаскиванием цели, удержание и отпускание вала, режимы позиция/колесо, калибровка середины, все параметры EEPROM, смена ID и скорости, дамп регистров 0–70, журнал пакетов.

### Подготовка приводов (перед сборкой)
Новые ST3215 приходят с ID 1, вал в случайном положении. Помощник проводит по очереди все 7 приводов (подключать по одному):
1. Найти привод.
2. Записать ID (по умолчанию 1–7 по суставам), скорость 1 Мбит/с, режим «позиция», пределы угла 0–4095.
3. Повернуть вал в середину (2048, 180°) и удерживать.
4. Надеть приводной фланец: 4 отверстия крестом «+» вдоль/поперёк длинной стороны корпуса, центральный винт М3, риска маркером на фланце и корпусе, подпись «ID N». После «Фланец надет» момент снимается.

3D-вид показывает фланец крупно и место привода в манипуляторе. Прогресс сохраняется в браузере.

### Манипулятор
3D-модель манипулятора, разбитая на звенья по осям приводов.

| Сустав | ID привода | Ось |
|---|---|---|
| 1 Поворот основания | 1 | вертикальная |
| 2 Плечо | 2 | горизонтальная |
| 3 Локоть | 3 | горизонтальная |
| 4 Поворот предплечья | 4 | вдоль предплечья |
| 5 Наклон кисти | 5 | горизонтальная |
| 6 Поворот кисти | 6 | вдоль кисти |
| Схват | 7 | шестерни, параллелограмм |

- Поза модели (все суставы 0°): плечо вертикально, предплечье горизонтально вперёд, кисть вниз, схват раскрыт (0° — раскрыт, ~70° — сомкнут).
- Для каждого сустава задаются ID, ноль, инверсия и пределы. «Принять текущую позу за позу модели» записывает текущее положение в привод как середину.
- Движение — SYNC WRITE: все суставы приходят в точку одновременно за заданное время. Реальное положение читается ~10 раз/с.
- Позы можно запоминать, проигрывать по порядку и по кругу. Настройки сохраняются в браузере и в JSON-файл.

## Протокол моста

USB 1 000 000 бит/с. Кадр: `A5 5A CMD LEN DATA XOR`, где XOR = CMD ^ LEN ^ байты DATA.

| CMD | Назначение | Ответ |
|---|---|---|
| 1 | Версия | `FTBR1` |
| 2 | Скорость шины (4 байта LE) | Установленная скорость |
| 3 | Обмен: таймаут_мс + пакет Feetech | Байты с шины без эха |
| 4 | Поиск: ID_от, ID_до, таймаут_мс | Список ответивших ID |

Светодиоды ESP32: LED1 — мост работает, LED2 — обмен, RGB зелёный/красный — привод ответил/нет ответа.

## Если не работает 3D

При ошибке WebGL страница пробует упрощённые режимы, а если не получается — показывает встроенные картинки. Что проверить: аппаратное ускорение в настройках браузера, `chrome://gpu` (`browser://gpu` в Яндекс Браузере), `chrome://flags` → «Override software rendering list», драйвер видеокарты или 3D в виртуальной машине. Без 3D всё остальное работает.
