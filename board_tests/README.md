# Тесты контроллера и модулей Kirus

Скетчи для первой проверки робототехнического контроллера «Кибернетический» (Ardu8) и модулей датчиков Kirus. Плата в Arduino IDE: *Arduino Uno* (верхний USB-C) или *ESP32 Wrover Module* (нижний USB-C). Положение DIP-переключателей написано в начале каждого скетча.

## Встроенная периферия и моторы

| Скетч | Плата | Что проверяет | Статус |
|---|---|---|---|
| `Ardu8_test` | Uno | Светодиоды (74HC595) и кнопки (74HC165) Arduino | ✅ проверен |
| `Ardu8_esp_test` | ESP32 | Светодиоды, кнопки и пищалка ESP32 | ✅ проверен |
| `Ardu8_esp_motors_test` | ESP32 | Поиск модулей моторов 71/72 на шине DXL, прокрутка моторов | ✅ проверен |
| `Ardu8_dxlmaster_test` | Uno | Библиотека DxlMaster2: ping, чтение регистров, мощность моторов | ✅ проверен |

## Модули Kirus

Подключение (все модули сразу): «Датчик линии» S1 → D3, S2 → D4; «Ультразвуковой дальномер» TRIG → D5, ECHO → D6; «Концевой выключатель» → D7.

| Скетч | Плата | Что делает | Статус |
|---|---|---|---|
| `Ardu8_Kirus_uSW` | Uno | «Концевой выключатель»: нажатие, счётчик, сброс BUT1 | ✅ проверен |
| `Ardu8_Kirus_Ultrasonic` | Uno | «Ультразвуковой дальномер»: расстояние, шкала на LED1–4, плоттер | ✅ проверен |
| `Ardu8_Kirus_Line` | Uno | «Датчик линии»: два канала, LED1/LED2, RGB | ✅ проверен |
| `Ardu8_Kirus_All` | Uno | Все три модуля сразу, вывод для плоттера | ✅ проверен |
| `Ardu8_Kirus_RJ12` | Uno | Модуль через RJ12 (XS9) одним кабелем | черновик |
| `Ardu8_Kirus_LineFollower` | Uno | Езда по линии с остановкой перед препятствием | черновик |
| `Ardu8_Kirus_Sender` + `Ardu8_esp_Kirus_Receiver` | Uno + ESP32 | Передача данных датчиков в ESP32 по UART | черновик |

Черновики на железе не проверены.
